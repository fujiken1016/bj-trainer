# BJ Trainer — ブラックジャック・トレーナー

ベーシックストラテジーとカードカウンティングの練習ツール。単一HTML・外部依存ゼロ。

## 機能
- **ストラテジー**：ハンド出題 → H/S/D/P/R を判定 → 正誤＋該当カテゴリの戦略表を丸ごと表示（現在のマスを枠で強調）
- **ラウンド進行**：スプリット後の各ハンドも最後までプレイ → ディーラーがルール通りドロー → WIN / LOSE / PUSH 判定
- **対応ルール**：S17/H17・ダブル制限(自由/9以上/10以上)・DAS・サレンダー(なし/レイト/アーリー)・デッキ数(1/2/4-8)・ホールカード(ピーク/ENHC/OBO)・Free Bet Blackjack
- **カウンティング**：Hi-Lo（ランニングカウント／1枚タグ付け）
- **間違いの振り返り**：不正解を記録し、同じ手・同じルールで再挑戦

各ルールトグルの ⓘ に用語解説付き。

## 検証
Free Bet の戦略表は Wizard of Odds の実ベット表と 290 セル全一致を確認済み。
ラウンド進行は 650 ラウンドの自動シミュレーション×3設定でエラー 0。
